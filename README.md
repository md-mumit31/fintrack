# 💰 FinTrack

### Modern Personal Finance Dashboard

FinTrack is a modern and responsive personal finance dashboard designed to help users track their income, expenses, budgets, and spending patterns through a clean and intuitive interface.

The project focuses on building a realistic financial dashboard experience using **HTML, CSS, and vanilla JavaScript**, with persistent browser storage through the **LocalStorage API**.

## 💾 Data Persistence

FinTrack uses the browser's LocalStorage API to persist transaction data.

This means users can:

1. Add transactions
2. Close or refresh the browser
3. Return to the application
4. Continue with their previously saved data

No backend or database is required for the current version.

## 📊 Core Functionality

### Transaction Management

Users can create, edit, delete, search, and filter financial transactions.

### Dashboard

The dashboard automatically calculates:

- Total balance
- Total income
- Total expenses
- Monthly income
- Monthly expenses
- Transaction count

### Budget Tracking

Users can set a monthly spending budget and monitor their progress through a visual indicator.

### Analytics

FinTrack groups expenses by category and provides a visual breakdown of spending.
